# Manage Contents / Content Diary

漫画・アニメ・映画・小説など、自分が見た／読んだ作品と、そのときの印象を記録し、個人ランキングとして残すためのスマートフォン向けコンテンツ日記プロトタイプです。

## コンセプト

- **まず自分が使いやすいことを優先**したスマートフォンUI
- 「作品データベース」よりも **自分の体験・印象・評価を残す日記** が中心
- 評価・タグ・メモ・視聴／読了状況をまとめて保存
- 登録履歴をもとにした **AIおすすめ** を主要機能として想定
- 将来的にユーザーが増えた場合は、協調フィルタリングによる推薦にも拡張可能

## プロトタイプで実装済み

- 漫画／アニメ／映画／小説のカテゴリ管理
- 視聴・読書ステータス管理
- 10点満点の個人評価
- 感想メモ・タグ・お気に入り登録
- 検索、カテゴリ・ステータス絞り込み
- 評価順の「マイランキング」
- 最近追加した作品の表示
- ローカルデータから好みを要約する「AIおすすめ」デモ
- 作品の新規追加・編集・削除
- JSONバックアップ／復元
- `localStorage` による端末内保存

## 使い方

ビルドは不要です。`index.html` をブラウザで開くだけで動作します。

GitHub Pages を有効化する場合は、リポジトリの Pages 設定で `main` ブランチのルートを公開対象にしてください。

## 構成

- `index.html` — 画面構造
- `styles.css` — スマートフォン中心のUI
- `app.js` — CRUD、検索、ランキング、推薦デモ、localStorage
- `docs/PRODUCT_SPEC.md` — 現時点のプロダクト方針
